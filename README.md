
# Word Counter

## Project Description
Word Counter is a simple Java utility that reads a text file and counts the total number of words.

This project is developed for the SWE 442 Software Configuration Management course.

## Features
- Read a text file.
- Count the total number of words.
- Display the result.
- Handle file-not-found errors.

## How to Run
1. Download the project.
2. Make sure Java JDK is installed.
3. Open a terminal in the project folder.
4. Compile the program:
   javac WordCounter.java
5. Run the program:
   java WordCounter
6. Enter the path of a text file.

## Example
Input file: sample.txt

Content:
Hello World
Welcome to Java

Output:
Total words: 5
